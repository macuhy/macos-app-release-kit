# 02 · 环境变量与密钥

所有 Secrets 都设置在**私有仓库**（CI 在那里运行）。逐项准备后用脚本一键写入。

## A. 签名证书 → `BUILD_CERTIFICATE_BASE64` / `P12_PASSWORD`

1. 在「钥匙串访问」或 Xcode 中导出你的 **Developer ID Application** 证书为 `.p12`（导出时设一个密码 = `P12_PASSWORD`）。
2. 转 base64：
```bash
bash scripts/export-cert.sh ~/Downloads/DeveloperID.p12
# 会打印 base64 字符串 → 即 BUILD_CERTIFICATE_BASE64
```
> 没有 Developer ID 证书？在 developer.apple.com → Certificates → "+" → **Developer ID Application** 创建并下载，导入钥匙串后再导出 .p12。

## B. 公证凭据 → `APPLE_ID` / `APPLE_TEAM_ID` / `APPLE_APP_PASSWORD`

- `APPLE_ID`：开发者账号邮箱
- `APPLE_TEAM_ID`：developer.apple.com → Membership 里的 10 位 Team ID
- `APPLE_APP_PASSWORD`：appleid.apple.com → 登录与安全 → **App 专用密码** → 生成一个

## C. Sparkle 签名密钥 → `SPARKLE_PRIVATE_KEY` / 公钥

```bash
# 下载 Sparkle 工具包：https://github.com/sparkle-project/Sparkle/releases
# 解压后在其 bin/ 目录运行一次：
./bin/generate_keys
#   → 私钥存入登录钥匙串，并打印 base64 公钥（= {{SPARKLE_PUBLIC_KEY}}，填进 CONFIG.md 和 Info.plist）

# 导出私钥用于 CI：
./bin/generate_keys -x sparkle_private_key.txt   # 导出私钥到文件
cat sparkle_private_key.txt                       # 内容 → SPARKLE_PRIVATE_KEY
# 用完务必删除：rm sparkle_private_key.txt
```

## D. 跨仓库发布令牌 → `RELEASE_REPO_PAT`

github.com/settings/tokens?type=beta → **Generate new token (fine-grained)**：
- Resource owner：`{{PUBLIC_OWNER}}`
- Repository access：Only select repositories → 选 `{{PUBLIC_REPO}}`
- Permissions：**Contents → Read and write**
- 复制生成的 token → `RELEASE_REPO_PAT`

## E. 自定义钥匙串密码 → `KEYCHAIN_PASSWORD`
随便设一个强密码（CI 里创建临时钥匙串用）。

---

## 一键写入所有 Secrets
填好下面的值后运行（脚本调用 `gh secret set`）：
```bash
export PRIVATE_REPO="{{PRIVATE_REPO}}"
export BUILD_CERTIFICATE_BASE64="$(bash scripts/export-cert.sh ~/Downloads/DeveloperID.p12)"
export P12_PASSWORD="..."
export KEYCHAIN_PASSWORD="..."
export APPLE_ID="..."
export APPLE_TEAM_ID="..."
export APPLE_APP_PASSWORD="..."
export SPARKLE_PRIVATE_KEY="$(cat sparkle_private_key.txt)"
export RELEASE_REPO_PAT="..."

bash scripts/setup-secrets.sh
```

验证：
```bash
gh secret list --repo {{PRIVATE_REPO}}
# 应列出全部 8 个 secret
```
