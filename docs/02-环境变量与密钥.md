# 02 · 环境变量与密钥

共 **7 个 Secret**，设置在**私有仓库**（或组织级，见 docs/05）。逐项准备后用脚本一键写入。
（钥匙串密码不再需要 secret——workflow 用 `openssl rand` 临时随机生成。）

## A. 签名证书 → `DEVELOPER_ID_CERTIFICATE_P12` / `DEVELOPER_ID_CERTIFICATE_PASSWORD`

1. 在「钥匙串访问」或 Xcode 中导出你的 **Developer ID Application** 证书为 `.p12`（导出时设一个密码 = `DEVELOPER_ID_CERTIFICATE_PASSWORD`）。
2. 转 base64：
```bash
bash scripts/export-cert.sh ~/Downloads/DeveloperID.p12
# 会打印 base64 字符串 → 即 DEVELOPER_ID_CERTIFICATE_P12
```
> 没有 Developer ID 证书？在 developer.apple.com → Certificates → "+" → **Developer ID Application** 创建并下载，导入钥匙串后再导出 .p12。

## B. 公证凭据 → `APPLE_ID` / `APPLE_TEAM_ID` / `APPLE_ID_PASSWORD`

- `APPLE_ID`：开发者账号邮箱
- `APPLE_TEAM_ID`：developer.apple.com → Membership 里的 10 位 Team ID（也要填进 `ExportOptions.plist`）
- `APPLE_ID_PASSWORD`：appleid.apple.com → 登录与安全 → **App 专用密码** → 生成一个

## C. Sparkle 签名密钥 → `SPARKLE_PRIVATE_KEY` / 公钥

```bash
# 下载 Sparkle 工具包：https://github.com/sparkle-project/Sparkle/releases
bash scripts/export-sparkle-key.sh ./bin
#   → 打印 base64 公钥（= {{SPARKLE_PUBLIC_KEY}}，填进 Info.plist 的 SUPublicEDKey）
#   → 私钥导出到 sparkle_private_key.txt（= SPARKLE_PRIVATE_KEY）
# 写入 secret 后务必删除：rm sparkle_private_key.txt
```

## D. 跨仓库发布令牌 → `RELEASE_REPO_PAT`

github.com/settings/tokens?type=beta → **Generate new token (fine-grained)**：
- Resource owner：`{{PUBLIC_OWNER}}`
- Repository access：Only select repositories → 选 `{{PUBLIC_REPO}}`
- Permissions：**Contents → Read and write**
- 复制生成的 token → `RELEASE_REPO_PAT`

---

## 一键写入所有 Secrets
填好下面的值后运行（脚本调用 `gh secret set`）：
```bash
export PRIVATE_REPO="{{PRIVATE_REPO}}"
export DEVELOPER_ID_CERTIFICATE_P12="$(bash scripts/export-cert.sh ~/Downloads/DeveloperID.p12)"
export DEVELOPER_ID_CERTIFICATE_PASSWORD="..."
export APPLE_ID="..."
export APPLE_TEAM_ID="..."
export APPLE_ID_PASSWORD="..."
export SPARKLE_PRIVATE_KEY="$(cat sparkle_private_key.txt)"
export RELEASE_REPO_PAT="..."

bash scripts/setup-secrets.sh
```

验证：
```bash
gh secret list --repo {{PRIVATE_REPO}}
# 应列出全部 7 个 secret
```
