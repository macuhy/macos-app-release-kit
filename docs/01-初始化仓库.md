# 01 · 初始化两个仓库

你需要两个仓库：**私有仓库（源码 + CI）** 和 **公共仓库（分发产物 + 更新源）**。

前置：安装并登录 GitHub CLI
```bash
brew install gh
gh auth login
```

## 1. 私有仓库（源码）

如果你已有源码仓库，跳过创建，直接进第 3 步加 workflow。

```bash
# 新建私有仓库（已有则跳过）
gh repo create {{PRIVATE_REPO}} --private --clone
cd $(basename {{PRIVATE_REPO}})

# App 源码放进来后，加上 workflow 目录
mkdir -p .github/workflows
# 把 templates/release.yml 复制过来（变量已替换）
cp /path/to/macos-app-release-kit/templates/release.yml .github/workflows/release.yml
git add .github/workflows/release.yml
git commit -m "ci: 添加 macOS 自动发布流程"
git push
```

## 2. 公共仓库（分发 + 更新源）

```bash
# 新建公共仓库
gh repo create {{PUBLIC_REPO}} --public --clone
cd $(basename {{PUBLIC_REPO}})

# 放一个初始 appcast.xml（首次发布前，Sparkle 拉到空 feed 不报错）
cp /path/to/macos-app-release-kit/templates/appcast-initial.xml appcast.xml

cat > README.md <<'EOF'
# {{APP_NAME}} Releases

本仓库自动发布 {{APP_NAME}} 的 macOS 版本。
- 最新安装包见 [Releases](../../releases)
- 更新源：`appcast.xml`（由 CI 自动维护，请勿手动改）
EOF

git add appcast.xml README.md
git commit -m "init: 初始化分发仓库"
git push
```

## 3. 验证
```bash
# 确认 appcast 可公开访问（这就是 App 的 SUFeedURL）
curl -I {{APPCAST_URL}}
# 期望返回 200
```
